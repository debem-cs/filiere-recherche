# Kapitza Pendulum — Vibrational Stabilisation Simulations

![MATLAB](https://img.shields.io/badge/MATLAB-script-orange)
![Solver](https://img.shields.io/badge/solver-ode45-blue)
![Status](https://img.shields.io/badge/status-research%20code-lightgrey)

Time-domain simulation and animation of the **Kapitza pendulum** — a rigid pendulum whose pivot is driven at high frequency, which stabilises the *inverted* position — and of its **tilted-excitation generalisation**, in which the pivot oscillates along a line inclined by an angle $\beta$ from the vertical and the pendulum can be held at an arbitrary target angle $\phi_s$.

The repository contains two self-contained MATLAB scripts:

| Script | Model | Purpose |
|---|---|---|
| [`Kapitza_pendulum.m`](Kapitza_pendulum.m) | Vertical pivot excitation ($\beta = 0$) | Baseline: classical Kapitza pendulum, stabilisation of $\theta = 0$ |
| [`Kapistza_pendumlum_beta_plots.m`](Kapistza_pendumlum_beta_plots.m) | Tilted pivot excitation ($\beta \neq 0$) | Stabilisation of an arbitrary $\phi_s$, with automatic selection of $\beta$, stability check, and error analysis |

The tilted model follows M. Ciężkowski, *J. Sound Vib.* **491** (2021). Equation numbers cited in the code and in this document refer to that paper.

## Physical model

Angles are measured from the **upward** vertical, so $\theta = 0$ is the inverted position. The pivot moves along a line at angle $\beta$ from the vertical:

$$
\mathbf{r}_p(t) = A\cos(\omega t)\,\begin{bmatrix}\sin\beta \\ \cos\beta\end{bmatrix}, \qquad \omega = 2\pi f_{exc}
$$

The equation of motion (with viscous damping $\gamma$) is

$$
L\,\ddot\theta = g\sin\theta + A\omega^{2}\cos(\omega t)\,\sin(\beta-\theta) - L\gamma\,\dot\theta
$$

For $\beta = 0$ this reduces to the classical Kapitza equation

$$
\ddot\theta + \gamma\dot\theta - \frac{g - A\omega^{2}\cos(\omega t)}{L}\sin\theta = 0
$$

which is what Script 1 integrates. The damping coefficient is parametrised through a damping ratio, $\gamma = 2\zeta\sqrt{g/L}$.

### High-frequency (averaged) behaviour

Introduce the dimensionless excitation strength

$$
\lambda = \frac{(A\omega)^{2}}{2gL}
$$

First-order averaging over one excitation period gives the slow dynamics (undamped)

$$
\ddot\theta_{slow} = \frac{g}{L}\sin\theta + \frac{A^{2}\omega^{2}}{4L^{2}}\sin\!\big(2(\beta-\theta)\big)
$$

**Equilibrium.** Setting the right-hand side to zero at $\theta = \phi_s$ gives the tilt angle required to hold a chosen $\phi_s$ (Eq. 6 of the paper, as implemented in Script 2):

$$
\beta = \tfrac{1}{2}\left(2\phi_s - \arcsin\frac{2\sin\phi_s}{\lambda}\right)
$$

**Stability.** The equilibrium is a minimum of the effective potential if the slow stiffness is positive, which requires

$$
\lambda > \lambda_{min}(\phi_s) =
\begin{cases}
\sqrt{4\sin^{2}\phi_s + \cos^{2}\phi_s}, & \phi_s \le \pi/2 \\[2pt]
2\sin\phi_s, & \phi_s > \pi/2
\end{cases}
$$

**Slow (small-oscillation) frequency** about $\phi_s$ — the curvature of the effective potential:

$$
\omega_0^{2} = \frac{A^{2}\omega^{2}}{2L^{2}}\cos\!\big(2(\beta-\phi_s)\big) - \frac{g}{L}\cos\phi_s
$$

**Classical limit.** For $\beta = 0$, $\phi_s = 0$: $\lambda_{min} = 1$, i.e. $(A\omega)^2 > 2gL$ — Kapitza's criterion, which is the check used in Script 1.

## Script 1 — classical Kapitza pendulum

**File:** `Kapitza_pendulum.m`

Simulates a pendulum with a purely vertical pivot motion $y_p(t) = A\cos(\omega t)$, starting near the inverted position, and animates it next to the $\theta(t)$ history.

### Parameters

| Variable | Default | Unit | Description |
|---|---|---|---|
| `g` | 9.81 | m/s² | Gravitational acceleration |
| `L` | 0.25 | m | Pendulum length |
| `zeta` | 0.01 | – | Damping ratio ($\gamma = 2\zeta\sqrt{g/L}$) |
| `A` | 0.07 | m | Pivot amplitude |
| `f_exc` | 6.0 | Hz | Pivot excitation frequency |
| `theta0` | 10° | rad | Initial angle from the upward vertical |
| `omega0` | 0 | rad/s | Initial angular velocity |
| `t_end` | 100 | s | Total simulated time |
| `inicio_anim`, `fim_anim` | 10, 60 | s | Animation window |
| `fps` | 60 | 1/s | Output sampling / playback rate |
| `trace_len` | 80 | samples | Length of the bob trail |

### Behaviour

1. Computes $(A\omega)^2$ against $2gL$ and prints the ratio; reports whether the high-frequency criterion is satisfied. This check is **advisory** — the simulation runs regardless.
2. Integrates the full (non-averaged) equation with `ode45`.
3. Animates the pendulum (rod, bob, pivot, trail) alongside $\theta(t)$ over the selected window.

With the defaults the ratio is $\approx 1.42$ and $\theta$ decays to the inverted equilibrium.

## Script 2 — tilted-excitation pendulum

**File:** `Kapistza_pendumlum_beta_plots.m`

Given a **target angle** $\phi_s$, the script (i) checks that the excitation is strong enough, (ii) computes the tilt angle $\beta$ that makes $\phi_s$ a stable equilibrium, (iii) integrates the full nonlinear model, and (iv) reports how closely the pendulum holds the target.

### Parameters

| Variable | Default | Unit | Description |
|---|---|---|---|
| `g`, `L`, `zeta` | 9.81, 0.25, 0.01 | – | As in Script 1 |
| `A` | 0.09 | m | Pivot amplitude |
| `f_exc` | 6.0 | Hz | Pivot excitation frequency |
| `phi_s` | 60° | rad | **Target equilibrium angle** |
| `theta0` | `phi_s + 10°` | rad | Initial angle (perturbed from target) |
| `omega0` | 0 | rad/s | Initial angular velocity |
| `t_end` | 100 | s | Total simulated time |
| `start_anim`, `end_anim` | 20, 60 | s | Animation window |
| `fps` | 60 | 1/s | Output sampling / playback rate |
| `trace_len` | 30 | samples | Length of the bob trail |
| `save_png` | `true` | – | Export the final figure at 300 dpi |

### Workflow

```
parameters ──► lambda, lambda_min ──► guard ──► beta (Eq. 6) ──► omega_0 ──► ode45 ──► error analysis ──► animation ──► diagnostics / PNG
```

1. **Stability check.** Computes $\lambda$ and $\lambda_{min}(\phi_s)$. If $\lambda \le \lambda_{min}$ the script stops with an `error()` — see [Troubleshooting](#troubleshooting).
2. **Tilt angle.** Computes $\beta$ from Eq. 6 and prints it.
3. **Slow frequency.** Computes $\omega_0^2$; stops with an `error()` if it is not positive (no potential minimum at $\phi_s$).
4. **Integration.** `ode45` on the full model, sampled on a uniform grid $\Delta t = 1/f_{ps}$.
5. **Error signal.** $e(t) = \phi_s - \theta(t)$ in degrees, plus a **period average** of $e$ — a moving average over exactly one excitation period, normalised at the edges — which removes the fast component and leaves the slow tracking error.
6. **Figure and animation.** Three panels: animation with the pivot track and target direction, $\theta(t)$ with the target line, and $e(t)$ with its period average.
7. **Diagnostics.** Mean, standard deviation and mean error of $\theta$ over the last 10 s; saves `tilted_pendulum.png`.

### Console output

```
lambda          = 2.3470
lambda required = 1.8028   (phi_s = 60.0 deg)
beta            = 0.6322 rad = 36.22 deg
slow frequency  = 6.521 rad/s  -> period 0.9635 s
```

### Reference results (default parameters)

| Quantity | Value |
|---|---|
| $\lambda$ / $\lambda_{min}$ | 2.347 / 1.803 |
| $\beta$ | 36.22° |
| $\omega_0$ | 6.52 rad/s (period 0.96 s) |
| Mean $\theta$, last 10 s | ≈ 60.6° (target 60°) |
| Std of $\theta$, last 10 s | ≈ 5.9° |
| Mean error, last 10 s | ≈ −0.6° |

> These reference values come from an independent reproduction of the same model and tolerances (Python / SciPy), not from a MATLAB run. Expect agreement to the printed precision; replace with your own MATLAB output if you prefer.

**Reading the numbers.** The std of $\theta$ is dominated by the fast micro-oscillation at the excitation frequency, whose amplitude is approximately $(A/L)\,|\sin(\beta-\phi_s)| \approx 8.3°$ (std $\approx 5.9°$), *not* by slow drift. The slow tracking error is given by the period-averaged curve in the bottom-right panel. The residual offset of a fraction of a degree is consistent with the finite $A/L$ and the first-order nature of the averaging.

## Numerical methods

| Item | Setting | Rationale |
|---|---|---|
| Integrator | `ode45` (adaptive Dormand–Prince RK5(4)) | Non-stiff problem; smooth right-hand side |
| Tolerances | `RelTol = 1e-9`, `AbsTol = 1e-11` | Slow dynamics are obtained from a small residual of large fast terms; tight tolerances avoid accumulated phase error |
| `MaxStep` | `T/100` (`T` = excitation period) | **Essential.** With default adaptive stepping the solver can step across whole excitation periods, averaging the drive out numerically and reporting *spurious* stability |
| Output grid | `tspan = 0:1/fps:t_end` | Uniform samples; direct `ode45` output, no dense-output interpolation |
| Period average (Script 2) | `conv` with a boxcar of $N = \mathrm{round}(T/\Delta t)$ samples, edge-normalised | Exactly one excitation period, so the fast component cancels |

## Verification

- **β = 0 recovery.** Script 2's model, stability threshold and $\omega_0^2$ reduce to the classical Kapitza results at $\beta = \phi_s = 0$ ($\lambda_{min} = 1$; $\omega_0^2 = A^2\omega^2/2L^2 - g/L$), so Script 1 is a consistency anchor for Script 2.
- **Closed-form checks.** The equilibrium condition and slow stiffness quoted above follow from first-order averaging of the equation of motion and match the expressions implemented in the script.
- **Solver sensitivity.** A useful regression test is to remove `MaxStep` and compare against the default run: a stable configuration may then appear to fail (or vice-versa), which confirms that the constraint is active.

## Troubleshooting

| Message | Cause | Fix |
|---|---|---|
| `lambda = … is below the required …` | Excitation too weak to stabilise $\phi_s$ | Increase `A` or `f_exc`, or reduce `phi_s` |
| `No potential minimum at phi_s (w0^2 = …)` | Slow stiffness ≤ 0 at the computed $\beta$ | Same as above; also check `phi_s` is within a range where $\lambda_{min}$ is met |
| `Animation window [...] lies outside the simulation` | `start_anim`/`end_anim` beyond `t_end` | Adjust the window or `t_end` |
| Complex-valued `beta` | $2\sin\phi_s/\lambda > 1$ | Prevented by the stability guard; appears only if the guard is edited out |
| Animation runs slower than real time | `drawnow` cost at high `fps` | Lower `fps` or `trace_len`; `pause(1/fps)` is the lower bound |

## Limitations

- **Averaging validity.** The formulas for $\beta$, $\lambda_{min}$ and $\omega_0$ are first-order high-frequency results. They are accurate when the excitation is fast compared with the slow dynamics and $A \ll L$. Here $A/L = 0.28$–$0.36$, so small systematic offsets are expected.
- **Necessary vs. sufficient.** $\lambda > \lambda_{min}$ is a criterion of the averaged system, not a Floquet-based guarantee for the full time-periodic system. A Floquet/monodromy analysis would be needed for a rigorous boundary.
- **Local stability only.** The initial condition is a 10° perturbation from the target; basins of attraction are not mapped.
- **Open-loop.** The pivot motion is prescribed; there is no feedback.
- **Model scope.** Rigid massless rod, point-mass bob, linear viscous damping, no pivot friction, ideal (kinematically prescribed) drive.
- **Animation coupling.** Simulation, animation and file export run in one blocking script; closing the figure aborts the animation loop and skips the PNG export.
